# 案例二 · 物理校验记录（教材第 5 题）

> 对应论文第四章案例二「带电粒子先加速、再偏转」。本页记录资源所用物理模型、统一约定、精确解与实测读数的一致性，供论文交稿前复核。

## 1. 题目与来源

人教版《普通高中教科书·物理 必修第三册》第十章第 5 节「练习与应用」第 5 题（教材第 49 页）：
电子由静止经 1000 V 电压加速，再垂直进入场强 5000 N/C 的匀强偏转电场，偏转电极长 6 cm，求出射速度大小及其与入射方向的夹角。

## 2. 统一约定（Manim 与 HTML 一致）

| 项目 | 约定 |
|---|---|
| 符号 | $e>0$ 为电子电荷量**大小**，电子实际电荷 $-e$；$m_e$ 为电子质量 |
| 已知量 | $U_0=1000\ \mathrm{V}$、$E=5000\ \mathrm{N/C}$、$L=6\ \mathrm{cm}$ |
| 坐标 | 向右 $+x$、向上 $+y$ |
| 运动 | 电子**向右加速、向上偏转** |
| 加速区 | 左板负、右板正；电场向左，电子受力向右 |
| 偏转区 | 上板正、下板负；电场向下，电子受力向上 |
| 假设 | 电子由静止出发；偏转场匀强；忽略重力、边缘效应、相对论修正 |
| 板距 | **题目未给出**，推导中不作为已知量 |

## 3. 精确解（应与资源显示一致）

$$
eU_0=\tfrac12 m_e v_0^2 \;\Rightarrow\; v_0=\sqrt{\frac{2eU_0}{m_e}}
$$

$$
t=\frac{L}{v_0},\qquad a_y=\frac{eE}{m_e},\qquad
v_y=a_y t=\frac{eEL}{m_ev_0}
$$

$$
\frac{v_y}{v_0}=\frac{EL}{2U_0}=\frac{3}{20},\qquad
v_{\text{出}}=\sqrt{v_0^2+v_y^2}=\frac{\sqrt{409}}{20}\,v_0
=\frac{\sqrt{409}}{20}\sqrt{\frac{2eU_0}{m_e}}
$$

$$
\tan\theta=\frac{3}{20},\qquad \theta=\arctan\!\left(\frac{3}{20}\right),\qquad
|y|=\frac{EL^2}{4U_0}=\frac{9}{2000}\ \mathrm{m}
$$

> 注意：$3/20$ 是**正切值**，不是角度本身；偏转位移**大小**为 $9/2000\ \mathrm{m}=4.5\ \mathrm{mm}$，方向向上。

## 6. 表述校正（本案例相关）

1. 原「偏转量与粒子种类无关」改为「**偏转位移大小**相同，$|y|=|U|L^2/(4dU_0)$」；不同电性的粒子在同一偏转场中**方向相反**，不能笼统说成相同。
2. 加速区极性随粒子电荷符号自动调整：电子为左负右正，质子/α 为左正右负，任何粒子都从静止被加速进入偏转区。
3. 回旋加速器（案例三）：「半径只由速度决定」改为「对同一粒子且磁感应强度不变时，轨道半径随速度增大」；$r\propto\sqrt{n}$ 中的 $n$ 明确为**从静止开始、每次经过相同加速电压的累计加速次数**；周期不变的结论限定为固定粒子、匀强磁场、非相对论模型。

## 7. HTML 画面一致性审查（无头浏览器实测）

在 1366×768 与 1920×1080 下用真实指针事件与画布像素测量完成，结论如下。

### 7.1 读数与公式逐个相等

取两组参数（A：教材预设 $U_0=1000$ V、$U=100$ V、$L=6$ cm、$d=2$ cm；B：自定 $U_0=1600$ V、$U=-240$ V、$L=8$ cm、$d=2.5$ cm），电子、质子、α 三种粒子的 $v_0$、$v_y$、$v_{\text{出}}$、$\theta$、$|y|$ 与独立公式计算值**按显示精度逐位相等**，抽屉里的 $E$、$a$、$t$、$y$ 也一致。

### 7.2 方向自洽（三种粒子 × 两种极板极性）

| 粒子 | 加速区 | 偏转区（$U>0$） |
|---|---|---|
| 电子（$-e$） | 左板负、右板正；E 向左，F 向右 | 上板正、下板负；E 向下，F 向上，轨迹上偏 |
| 质子 / α（$+q$） | 左板正、右板负；E 向右，F 向右 | 同上，F 向下，轨迹下偏 |

$U<0$ 时偏转区极性、E、F、轨迹全部反转；三种粒子均实测。**加速区极性随粒子电性自动翻转**，任何粒子都向右加速进入偏转区。

### 7.3 画布几何与角度一致性

| 项目 | 实测 |
|---|---|
| 速度矢量像素测角（A / B） | 8.531°（理论 8.5308°） / 13.496°（理论 13.4957°） |
| $v_y/v_x$ | 0.1500 / 0.2400 |
| 轨迹像素拟合角 | 8.67° / 13.58–13.62°（与 θ 差 ≤0.23°，属光晕与抗锯齿的拟合误差） |
| 画布 x/y 比例 | 同为 3200 px/m，$L/d$ 像素比 = 真值，无“14° 画成 30°”式失真 |

### 7.4 已修正的缺陷

| 现象 | 原因 | 改法 |
|---|---|---|
| **$L=10$ cm 时出射角被画成 12.43°，真值 8.53°** | 矢量末端单独 clamp，导致竖直分量被截短而水平分量不变 | 改为等比缩放并设统一矢量化上限，复测 8.531° |
| 状态已显示「已离开电场」，画布仍画着力 F | 只判电场是否为零，未判粒子是否在板间 | 以 `inField` 为条件，出板后 F 消失、轨迹按匀速直线 |
| F 与 $v_y$ 两支箭头同轴重叠 | 二者都从粒子竖直绘制 | F 移至粒子左侧 16 px（虚线连接），$v_y$ 起点偏移，标签分开 |
| 画布上没有 θ 角弧 | 只在读数里给角度 | 在 $v$ 与 $v_x$ 之间加角弧（板间标瞬时 $\theta(t)$，出板标 $\theta$） |
| 轨迹从实心阳极板穿过 | 极板未开孔 | 两块极板中心开 32 px 孔，粒子从孔中通过 |
| $y$ 标尺横穿轨迹 | 标尺起点固定 | 改为粒子右侧 30 px、由中线量到当前位置，随播放移动 |
| 撞板标记在未撞板时就出现 | 判定用了“是否算出撞板”而非“是否已到撞板位置” | 仅在 $t=1$ 且撞板时绘制 |
| “偏转量与粒子种类无关” | 未限定大小 | 改为「偏转位移**大小**相同，方向相反」 |

### 7.5 边界情形

| 情形 | 实测 |
|---|---|
| $U=0$ | 轨迹最大偏离 0.67 px（抗锯齿），$\theta=0$，F 与 $v_y$ 不绘制 |
| 撞板（$L=10$ cm、$d=1$ cm、$U=400$ V） | $t=1.19$ ns，距入口 $x=2.2$ cm $=0.22L$，$y=5.0\ \mathrm{mm}=d/2$，轨迹在板面截断，板外无轨迹像素 |
| 出板后 | F 消失，速度矢量保持出射方向，状态显示「已离开电场」 |
